Capstone Project: ESG Data Automation Platform

Project Overview

During my diploma studies at Temasek Polytechnic, I developed an automated data extraction and processing workflow for an ESG (Environmental, Social, and Governance) compliance platform using UiPath and Alteryx.*

Background and Motivation

Environmental, Social, and Governance (ESG) reporting has become increasingly critical for organizations to demonstrate their commitment to sustainable practices. However, ESG data collection is often: - Manual and time-consuming: Extracting data from multiple sources and formats - Error-prone: Human data entry mistakes affecting accuracy - Inconsistent: Different data formats across various reporting systems - Resource-intensive: Taking up valuable analyst time that could be spent on insights

Project Objectives

The primary goal was to streamline ESG data management by:

  1. Automating data extraction from multiple sources (Excel spreadsheets, PDFs, web portals)
  2. Standardizing data formats across different reporting frameworks (GRI, SASB, TCFD)
  3. Validating data quality with automated error checking and flagging
  4. Reducing processing time from days to hours
  5. Improving accuracy by minimizing manual data entry

Technologies and Tools Used

Core Technologies

  • UiPath: Robotic Process Automation (RPA) platform for workflow automation
  • Alteryx: Data preparation and blending tool for ETL processes
  • Python: Custom scripting for data validation and transformation
  • Power BI: Dashboard creation for data visualization and insights
  • Microsoft Excel: Data source and validation interface

Technical Architecture

Data Sources → UiPath (Extraction) → Alteryx (Transformation) → Database → Power BI (Visualization)

Key Features Implemented

1. Automated Data Extraction

  • Built UiPath robots to extract data from:
    • PDF sustainability reports
    • Excel templates from different departments
    • Web-based ESG disclosure platforms
    • Email attachments from stakeholders

2. Data Transformation Pipeline

  • Created Alteryx workflows to:
    • Standardize different date formats (DD/MM/YYYY, MM-DD-YY, etc.)
    • Convert units (metric tons to kg, kWh to MWh)
    • Map data to appropriate ESG frameworks
    • Handle missing or incomplete data

3. Quality Assurance Checks

  • Implemented validation rules:
    • Numeric range checks (e.g., energy consumption within expected bounds)
    • Completeness verification (all required fields populated)
    • Cross-referencing with previous period data for anomaly detection
    • Duplicate entry identification

4. Error Handling and Logging

  • Built robust error management:
    • Exception handling for missing files or inaccessible sources
    • Detailed logging of all automation steps
    • Email notifications for critical failures
    • Manual intervention queue for complex cases

Challenges and Solutions

Challenge 1: Inconsistent Data Formats

Problem: Different departments submitted ESG data in varying formats, making standardization difficult.

Solution: - Created comprehensive data mapping templates - Developed Alteryx workflows with dynamic field recognition - Implemented fuzzy matching for similar-but-not-identical field names - Built validation layer to flag non-standard formats for manual review

Challenge 2: PDF Data Extraction Accuracy

Problem: UiPath’s OCR struggled with scanned PDFs and complex table layouts.

Solution: - Implemented multiple extraction strategies (native PDF reading vs. OCR) - Used anchor-based extraction for structured tables - Added post-extraction validation by cross-checking totals - Created manual review process for low-confidence extractions

Challenge 3: System Integration

Problem: Connecting UiPath, Alteryx, and the company’s database systems securely.

Solution: - Used API connections where available - Implemented secure file transfer protocols - Created intermediate staging database for data handoffs - Established clear data governance and access controls

Results and Impact

Quantifiable Achievements

  • 80% reduction in processing time: What took 2-3 days now completes in 4-6 hours
  • 95%+ accuracy rate: Automated validation reduced data entry errors significantly
  • 500+ hours saved annually: Freed analysts to focus on insights rather than data collection
  • Scalability: System handles 3x more data sources without additional staff

Qualitative Benefits

  • Improved data quality: Consistent formatting and validation rules
  • Faster reporting cycles: Ability to generate ESG reports on-demand
  • Better audit trail: Complete logging of data lineage and transformations
  • Enhanced stakeholder confidence: More reliable and timely ESG disclosures
