Reflection on the Use of GenAI

My Experience Using GenAI for This Assessment

The GenAI Tool I Used

For this assessment, I primarily used Claude (by Anthropic) as my GenAI assistant. I chose Claude because:

  • It’s specifically designed for coding and technical tasks
  • Provides detailed, step-by-step explanations
  • Offers contextual understanding of web development and Quarto
  • Available through my university resources

I also occasionally referenced ChatGPT for comparison and alternative perspectives on certain technical challenges.

How GenAI Helped Me Complete This Assessment

1. Setting Up the Quarto Website

When I first started, I was unfamiliar with Quarto’s syntax and structure. Claude helped me: - Understand the purpose of _quarto.yml configuration file - Learn proper YAML indentation (which caused me initial errors!) - Set up the correct output-dir: docs for GitHub Pages deployment

Example: When my navigation bar displayed raw YAML text instead of working links, Claude identified the formatting issue and provided a corrected structure with proper indentation.

2. Markdown Formatting and Syntax

GenAI was invaluable for learning Markdown quickly: - How to embed images: ![alt text](path/to/image.png) - Creating headers, lists, and emphasis - Troubleshooting image path issues (like when I used photo.jpg but the file was actually photo.jpg.png)

3. Git Version Control Guidance

One of my biggest challenges was understanding the Git workflow. Claude helped me: - Understand the difference between local rendering (localhost) and the live GitHub Pages site - Learn the commit-push cycle: git add → git commit → git push - Troubleshoot why my changes appeared locally but not on the live website

Example: When I asked “why after committing I don’t see anything in my git”, Claude explained that an empty Git tab means everything is committed successfully - this was actually correct behavior, not an error!

4. Content Structure and Organization

For the data visualization page, I showed Claude my Intermodal Transfer Analysis dashboard, and it helped me: - Structure the content with proper sections (What, Why, How) - Articulate the technical implementation details - Frame the story and insights in a clear, professional manner

Benefits of Using GenAI

Immediate, Personalized Learning - Unlike searching through documentation, GenAI provided answers specific to my exact problem - Explanations were tailored to my level of understanding - Available 24/7 when I worked on assignments late at night

Error Diagnosis and Debugging - When things didn’t work, I could paste screenshots or error messages - GenAI identified issues I wouldn’t have caught (like file extension mismatches) - Provided multiple solutions when one approach didn’t work

Learning Reinforcement - Each interaction taught me not just “how” but “why” - Built my confidence to experiment and try new approaches - Reduced frustration that often comes with learning new tools

Professional Writing Support - Helped structure technical explanations clearly - Suggested ways to present my work professionally - Improved the overall quality of my portfolio content

Challenges and Limitations I Encountered

1. Over-Reliance Risk

Initially, I found myself asking GenAI for everything without trying first. I realized this wasn’t helping me learn deeply. I had to consciously: - Attempt problems myself before asking for help - Use GenAI for guidance rather than complete solutions - Verify information rather than blindly accepting it

2. Context Limitations

Sometimes GenAI didn’t have full context of my specific setup: - Assumed certain files existed when they didn’t - Couldn’t see my actual file structure without me describing it - Required multiple clarifying questions to understand my exact situation

3. Version-Specific Information

GenAI’s knowledge has a cutoff date, so: - Some Quarto features might be newer than its training data - I still needed to check official documentation for the latest syntax - Plugin compatibility information required verification

4. Critical Thinking Still Required

GenAI provided suggestions, but I had to: - Evaluate which solution best fit my needs - Understand the implications of different approaches - Make final decisions about design and content
